# Handoff: 仕訳伝票入力 画面（社会福祉法人向け会計ソフトのWeb化）

## Overview
社会福祉法人（保育園・幼稚園など）向け会計ソフトの「仕訳伝票入力」画面を、既存のデスクトップソフトからWebアプリへ移行するためのデザインです。勘定科目・サービス区分・摘要・業者などの**入力補助（サジェスト付きドロップダウン）**を備え、入力した仕訳をその場で「仕訳帳」に追加・表示できます。

2つのUI案を用意しています。実装時はどちらか一方、または両方をプロトタイプとして提示する想定です。

- **フォーム型（`仕訳伝票_フォーム型.dc.html`）**: 1件ずつ丁寧に入力する伝票フォーム。仕訳帳は画面右端に固定表示（折りたたみ可能）。
- **スプレッドシート型（`仕訳伝票_スプレッドシート型.dc.html`）**: 1行の入力バーで素早く連続入力。左に縦メニュー、上部に検索パネル、下に仕訳帳テーブル。

## About the Design Files
このバンドルに含まれるファイルは **HTMLで作られたデザインリファレンス**です。見た目と挙動を示すプロトタイプであり、そのまま本番コードとして貼り付けるものではありません。

タスクは、これらのHTMLデザインを **対象コードベースの既存環境（React / Vue など）とそのパターン・ライブラリを使って再現すること**です。まだ環境が無い場合は、プロジェクトに最適なフレームワークを選定して実装してください。

> 技術メモ: 元プロトタイプは独自の軽量テンプレート/ロジック分離フレームワーク（`.dc.html`）で書かれています。この仕組み自体を再現する必要はありません。**画面・スタイル・挙動・状態管理のロジックだけ**を、対象環境の標準的な書き方（例: React 関数コンポーネント + useState）へ移植してください。ファイルは `<x-dc>` 内のマークアップ（テンプレート）と、末尾 `<script>` 内の `class Component extends DCLogic {…}`（ロジック）に分かれています。`{{ x }}` はデータバインディング、`sc-for`/`sc-if` は繰り返し/条件、`dc-import name="AssistPanel"` は子コンポーネント `AssistPanel.dc.html` の埋め込みです。

## Fidelity
**High-fidelity (hifi)** です。最終的な配色・タイポグラフィ・余白・角丸・インタラクションまで作り込んでいます。既存コードベースのライブラリ・パターンを使いつつ、見た目はピクセル単位で再現してください。

## 共通仕様（両案）

### データモデル
```
JournalEntry {
  id: number
  date: string      // "M/D" 形式（例 "8/1"）
  kari: string      // 借方科目
  kashi: string     // 貸方科目
  tekiyo: string    // 摘要（空可）
  amount: number    // 金額（整数、円）
}
```
表示金額は `Number.toLocaleString('ja-JP')` で3桁区切り。

### マスタデータ（サジェスト候補）
- **勘定科目 ACCOUNTS**（グループ見出し付き）:
  - 現金及び預金: 現金 / 普通預金（保育園）/ 当座預金（保育園）/ 小口現金
  - 事業未収金: 事業未収金 / 未収金 / 立替金 / 仮払金
  - 事業費: 保育材料費 / 給食費 / 水道光熱費（事業）/ 通信運搬費 / 賃借料（事業）/ 印刷製本費 / 消耗品費
  - 人件費: 職員俸給 / 法定福利費 / 特殊業務手当 / 扶養手当 / 時間外手当 / 通勤手当 / その他手当
  - 事業収益: 委託費収益 / その他の利用料収益 / 現金（収入）/ 受託事業収益 / 補助金収益
- **サービス区分 SERVICES**: 001 本部 / 002 保育事業 / 003 子育て支援 / 004 一時預かり / 005 地域支援
- **業者 VENDORS**: （なし）/ 東京電力 / ＮＴＴ東日本 / 中央リース / みどり商店 / 市役所 / 保護者
- **摘要 SUMMARIES**（よく使う摘要）: 健康保険 / 厚生年金 / 法定福利費 / 職員俸給 / 委託費ー８月分 / 電話料金 / ガス代ー７月分 / 副食費ー保護者より / コピー代 / 夏祭り用品 / 振込手数料
- **初期表示の仕訳帳（SEED）**: 8月分の仕訳を8〜10件（HTMLファイル内の `SEED` 配列を参照）。

### 入力補助パネル（AssistPanel）
科目・サービス区分・業者・摘要の各フィールドは、クリックでドロップダウンパネルを開く。
- 上部に検索入力（`id="assist-search"`）。開いた直後に自動フォーカス（約30ms後）。
- 入力文字で候補を部分一致フィルタ（`indexOf(q) >= 0`）。
- 勘定科目・摘要はグループ見出し付き、サービス区分・業者は見出しなしのフラットリスト。
- 候補クリックで値を確定しパネルを閉じる。`（なし）`を選ぶと空文字を設定。
- パネル外を `mousedown`（capture フェーズ）したら閉じる。判定は `e.target.closest('[data-assist]')` の有無。
- 該当0件のときは「該当なし」の空状態を表示。

### 取引区分チップ
`資金 / 事業 / その他` のトグルチップ（単一選択、同じものを再クリックで解除可）。選択中はアクセント色塗り＋白文字、未選択は白背景＋グレー枠。

### 登録処理（submit）
1. 借方科目・貸方科目・金額のいずれか未入力ならエラー文言「借方科目・貸方科目・金額を入力してください。」を表示して中断。
2. `id = nextId++` を採番し、フォーム値から `JournalEntry` を生成して仕訳帳に追加。
3. 借方・貸方・摘要・業者・金額をクリア（日付・取引区分・サービス区分は保持）。
4. 追加行は `lastAdded` に記録し、**約1.8秒のハイライトアニメーション**（背景 `#fff2c9` → 透明、`@keyframes rowin`）。
5. 追加後、仕訳帳スクロール領域（`id="journal-scroll"`）を一番下までスクロール。

### 月フィルター（両案共通）
仕訳帳を月で絞り込むチップ列。`全月` ＋ 仕訳帳に存在する月（重複除去し数値昇順）。選択中はアクセント色塗り。
- 表示 = `date.split('/')[0]` が選択月に一致する行のみ。
- 登録時、フィルターが特定月に絞られていて新規行の月と異なる場合は、**新規行の月へ自動切替**して追加行が必ず見えるようにする。

## Interactions & Behavior（まとめ）
- 補助ドロップダウン開閉、検索フォーカス自動移動、外側クリックで閉じる（capture フェーズの `mousedown`）。
- 取引区分チップのトグル、月フィルターのトグル。
- 登録による行追加＋ハイライト（1.8s）＋末尾スクロール。
- スプレッド型: 検索（Enter / ボタン）、クリア、空状態。
- フォーム型: 仕訳帳の折りたたみ／展開スライド（0.28s ease）、ナビ高さ実測でオフセット追従。
- **scrollIntoView は使わない**。スクロールは対象要素の `scrollTop = scrollHeight` で行う。

## State Management（対象環境の状態へ移植）
- `form`: { service, month, day, torihiki, kariKamoku, kashiKamoku, tekiyo, gyosha, amount }
- `assist`: { open, field, type, query }
- `journal`: JournalEntry[]（初期値 SEED）
- `lastAdded`: number | null（ハイライト対象）
- `err`: string
- `monthFilter`: string | null
- フォーム型のみ: `collapsed`（仕訳帳折りたたみ）, `topOffset`（実測オフセット）
- スプレッド型のみ: `search`, `applied`
- `nextId`: 採番カウンタ（1始まり）

## Design Tokens
