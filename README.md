# 仕訳伝票入力 画面（Webアプリ）

社会福祉法人（保育園・幼稚園など）向け会計ソフトの「仕訳伝票入力」画面を、既存のデスクトップソフトから
Webアプリへ移行するための実装。`design_handoff_journal_entry 2/README.md` の hifi デザイン仕様を
**Vite + React + TypeScript** で再構築したものです。

2案をフルスクリーンで切り替えて比較できます（画面下中央の切替バー）。

- **フォーム型**（緑 `#1f7a52`）: 1件ずつ丁寧に入力する伝票フォーム。仕訳帳は画面右端に固定表示（折りたたみ可能）。
- **スプレッドシート型**（青 `#2c5f9e`）: 1行の入力バーで素早く連続入力。左に縦メニュー、上部に検索パネル、下に仕訳帳テーブル。

## セットアップ

```bash
npm install      # 依存関係のインストール
npm run dev      # 開発サーバー起動（http://localhost:5180）
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド成果物をローカルサーバーで確認
```

> ⚠️ `dist/index.html` を Finder からダブルクリックで開くと、Chrome では ES モジュールが `file://` で
> ブロックされ空欄になります。必ず `npm run dev` または `npm run preview`（＝ローカルサーバー経由）で開いてください。

## 構成

```
src/
  main.tsx              エントリポイント
  App.tsx               画面切替（フォーム型 / スプレッドシート型）
  styles.css            グローバルCSS（hover/focus/keyframes/スクロールバー）
  types.ts              型定義
  data.ts               マスタ（科目/区分/業者/摘要）・メニュー・シード
  lib/
    format.ts           金額整形・補助候補生成・月抽出・rgba 等
  hooks/
    useEntryForm.ts     共有ロジック（form/assist/journal/月フィルタ/登録）
  components/
    AssistPanel.tsx     補助ドロップダウン（検索＋分類、mousedownで確定）
    AssistField.tsx     フィールドボタン＋補助ドロップダウン
    Chips.tsx           取引区分チップ（資金/事業/その他）
    MonthChips.tsx      月フィルターチップ（全月＋存在月）
    Menu.tsx            メニュー（横=フォーム型ナビ / 縦=サイドバー）
    FormScreen.tsx      フォーム型 画面
    SheetScreen.tsx     スプレッドシート型 画面
```

## 実装メモ

- **共通ロジック**は `useEntryForm` に集約。フォーム値・補助ドロップダウン・仕訳帳・月フィルタ・登録処理を提供。
  各画面はこれをベースに固有状態（フォーム型=折りたたみ/オフセット実測、スプレッド型=検索 `search`/`applied`）を追加。
- **補助ドロップダウン**: 候補選択は `onMouseDown` で確定（外側クリックの閉じる処理より先に発火）。検索は部分一致。
  勘定科目・摘要はグループ見出し付き、サービス区分・業者はフラット。
- **登録**: 借方科目・貸方科目・金額が必須。追加行を `rowin`（1.8s）でハイライトし `#journal-scroll` を最下部へ。
  月フィルタが別月に絞られている場合は新規行の月へ自動切替。日付・取引区分・サービス区分は保持。
  ※ `setState` 更新関数の中で副作用（採番・別 setState）を行わず、StrictMode の二重実行でも重複追加しない実装。
- **月フィルタ**（両案）: 仕訳帳に存在する月を数値昇順で列挙し、`全月`＋各月で絞り込み。
- **フォーム型**: アプリバー＋ナビの実測高さ（`useLayoutEffect`＋resize監視）を仕訳帳/トグル/main余白に反映。
  折りたたみは `transform: translateX(392px)` のスライド（0.28s）。
- **スプレッドシート型**: 検索は `検索`ボタン / Enter で `applied` を確定して初めて反映（インクリメンタルではない）。
  `クリア`で検索と月フィルタを初期化。登録時は検索条件をクリアして追加行が隠れないようにする。空状態表示あり。
- **マスタデータ**: 現状は `data.ts` の静的マスタ。本番では会計マスタAPIからの取得に差し替える想定。
- 元のデザインプロトタイプ（独自ランタイム `.dc.html`）は `design_handoff_journal_entry 2/` に参照用として残しています。

## 採用案の決定後

`App.tsx` から不要な画面を外し、切替バーを削除すれば単画面構成になります。共有の `useEntryForm` はそのまま利用できます。
